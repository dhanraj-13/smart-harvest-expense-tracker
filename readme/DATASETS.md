# Datasets in this repo

The dataset files are stored in:
- `cleaned dataset/`

## Files used for ML and backend
- `Tamilnadu_agriculture_yield_data.csv`  
  Used to train the yield model and to build crop master data.

- `rainfall_data.csv`  
  Used for a rainfall-aware adjustment (optional input).

## Files used as demo seed data (for farm management)
These files seed demo records into the database when the backend starts and tables are empty:
- `farm_users_sample.csv`
- `farm_fields_sample.csv`
- `farm_budgets_sample.csv`
- `farm_expenses_sample.csv`

## Other files (not required right now)
The repo also includes a few extra CSVs (for reference / future use):
- `Tamilnadu_Crop-Production.csv`
- `crop_production_history.csv`
- `rice_production.csv`
- `land_use.csv`

## Important note for GitHub
If you replace these datasets with your own real farm datasets, do not upload private data to a public repo.
